## Run

Double-click `run.bat`. The first run sets up `.venv` with [uv](https://docs.astral.sh/uv/).

## Develop

| Command | What |
|---|---|
| `uv add <package>` | Add a dependency |
| `uv run main.py` | Run it from a terminal |
| `setup.bat` | Recreate the environment |
